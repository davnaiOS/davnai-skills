# Light leak

Warm light washes across the picture.

**Use it for:** Openers, travel, lifestyle, soft transitions.

**In the plan** (inside `"fx": [...]`):

```json
{ "type": "light_leak", "lines": [1, 2] }
```

Optional: `"strength"` (default 1). Place it with `"lines"`, `"all": true` or `"at": "start"`/`"end"`.
