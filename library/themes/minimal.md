# Theme: minimal

Quiet and simple: small captions at the top, plain cuts, no boxes.

| | |
|---|---|
| Fonts | captions Poppins Medium, titles Poppins |
| Captions | 7 words, top, fade animation |
| Titles | slide, glow |
| Transitions | cut (also fade, dissolve) |
| Colour | natural |
| Frame | none |
| On emphasised words | none |
| Sounds | none |
| Own colours (no Brand Kit) | #18181B and #3F3F46 |
| Catalog pieces that suit it | caption-clip-wipe, fade-through, drift-hold, blur-in |

```json
"theme": "minimal"
```

The file: [themes/minimal.json](../../skills/davnai-video/themes/minimal.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
