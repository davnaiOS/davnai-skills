# Theme: luxury

Luxury: elegant display serif, thin gold lines, slow dissolves. For fashion, property and beauty.

| | |
|---|---|
| Fonts | captions Poppins Medium, titles Abril Fatface |
| Captions | 5 words, bottom, fade animation |
| Titles | glow, slide |
| Transitions | dissolve (also dissolve, fade, blur) |
| Colour | soft, film grain |
| Frame | border |
| On emphasised words | none |
| Sounds | transition: swoosh, motion: ding |
| Own colours (no Brand Kit) | #0C0A08 and #E6C67A |
| Catalog pieces that suit it | caption-weight-shift, gloss-sweep, curtain-reveal, focus-rack, logo-brand-close |

```json
"theme": "luxury"
```

The file: [themes/luxury.json](../../skills/davnai-video/themes/luxury.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
