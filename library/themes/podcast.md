# Theme: podcast

Podcast clips: the whole wide shot on a blurred background, big centred captions, key words stand out.

| | |
|---|---|
| Fonts | captions Poppins ExtraBold, titles Poppins ExtraBold |
| Captions | 3 words, middle, pop animation |
| Titles | pop, words |
| Transitions | cut (also dissolve, flash) |
| Colour | natural |
| Frame | none |
| On emphasised words | none |
| Sounds | transition: swoosh, motion: pop |
| Own colours (no Brand Kit) | #1E3A8A and #0F172A |
| Catalog pieces that suit it | caption-pill-karaoke, caption-highlight, count-up, conic-progress-ring, chat-message |

```json
"theme": "podcast"
```

The file: [themes/podcast.json](../../skills/davnai-video/themes/podcast.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
