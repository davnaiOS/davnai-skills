# Theme: playful

Bright and bouncy: rounded tilted stickers, big friendly letters, pops. For lifestyle, kids' and food content.

| | |
|---|---|
| Fonts | captions Righteous, titles Bungee |
| Captions | 3 words, bottom, bounce animation |
| Titles | bounce, pop, words |
| Transitions | slide_up (also slide_up, circle, zoom, whip) |
| Colour | vivid |
| Frame | none |
| On emphasised words | flash |
| Sounds | transition: swoosh, motion: pop |
| Own colours (no Brand Kit) | #FF5DA2 and #1B1B3A |
| Catalog pieces that suit it | caption-emoji-pop, confetti, badge-pop, gesture-tap, paper-collage-reveal |

```json
"theme": "playful"
```

The file: [themes/playful.json](../../skills/davnai-video/themes/playful.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
