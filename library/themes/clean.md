# Theme: clean

Friendly and modern: rounded brand-colour boxes, soft shadows, gentle pops.

| | |
|---|---|
| Fonts | captions Poppins, titles Poppins ExtraBold |
| Captions | 4 words, bottom, pop animation |
| Titles | pop, slide, words |
| Transitions | dissolve (also dissolve, slide, zoom) |
| Colour | soft |
| Frame | none |
| On emphasised words | none |
| Sounds | transition: swoosh, motion: pop |
| Own colours (no Brand Kit) | #4338CA and #0F172A |
| Catalog pieces that suit it | caption-highlight, caption-pill-karaoke, badge-pop, card-resize, count-up, cta-close |

```json
"theme": "clean"
```

The file: [themes/clean.json](../../skills/davnai-video/themes/clean.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
