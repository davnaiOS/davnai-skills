# Theme: news

Newsroom: solid bars, uppercase headlines, straight wipes. For updates, explainers and commentary.

| | |
|---|---|
| Fonts | captions Archivo Black, titles Bebas Neue |
| Captions | 5 words, bottom, fade animation, in a box |
| Titles | slide, words |
| Transitions | wipe (also wipe, slide, flash) |
| Colour | natural |
| Frame | none |
| On emphasised words | none |
| Sounds | transition: swoosh, motion: click |
| Own colours (no Brand Kit) | #B91C1C and #111111 |
| Catalog pieces that suit it | ticker-takeover, caption-clip-wipe, directional-wipe, count-up, chart-story |

```json
"theme": "news"
```

The file: [themes/news.json](../../skills/davnai-video/themes/news.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
