# Theme: neon

Night-time and techy: glowing outlines, dark panels, glitch cuts.

| | |
|---|---|
| Fonts | captions Audiowide, titles Audiowide |
| Captions | 3 words, bottom, fade animation, uppercase, glow |
| Titles | glow, typewriter, words |
| Transitions | glitch (also glitch, flash, blur) |
| Colour | cool |
| Frame | scanlines |
| On emphasised words | rgb |
| Sounds | transition: glitch, motion: ding |
| Own colours (no Brand Kit) | #0B0B1A and #22D3EE |
| Catalog pieces that suit it | caption-neon-glow, caption-neon-accent, rgb-glitch-text, chromatic-aberration-wipe, aurora-drift |

```json
"theme": "neon"
```

The file: [themes/neon.json](../../skills/davnai-video/themes/neon.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
