# Theme: retro

Retro: chunky letters, offset shadows, warm faded colour and film grain.

| | |
|---|---|
| Fonts | captions Bungee, titles Bungee |
| Captions | 3 words, bottom, pop animation, uppercase |
| Titles | bounce, pop, typewriter |
| Transitions | dissolve (also dissolve, circle, wipe) |
| Colour | retro, film grain |
| Frame | scanlines |
| On emphasised words | none |
| Sounds | transition: whoosh, motion: pop |
| Own colours (no Brand Kit) | #C2410C and #3B1F0E |
| Catalog pieces that suit it | grain-overlay, stop-motion-cadence, torn-paper-rip, colorama-wipe, caption-texture |

```json
"theme": "retro"
```

The file: [themes/retro.json](../../skills/davnai-video/themes/retro.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
