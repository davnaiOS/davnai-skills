# Theme: bold

Loud and punchy: big uppercase words, hard shadows, flashes and zooms. For hooks and fast talkers.

| | |
|---|---|
| Fonts | captions Anton, titles Anton |
| Captions | 2 words, middle, bounce animation, uppercase |
| Titles | words, bounce, pop |
| Transitions | flash (also flash, whip, zoom, glitch) |
| Colour | punchy |
| Frame | none |
| On emphasised words | shake |
| Sounds | transition: whoosh, motion: impact |
| Own colours (no Brand Kit) | #111111 and #FFE14D |
| Catalog pieces that suit it | caption-kinetic-slam, char-slam-explode, camera-shake, kinetic-center-build, shutter-slam, beat-accent |

```json
"theme": "bold"
```

The file: [themes/bold.json](../../skills/davnai-video/themes/bold.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
