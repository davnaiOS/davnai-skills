# Theme: editorial

Calm and premium: serif titles, one quiet line of captions at the top, film-like colour.

| | |
|---|---|
| Fonts | captions Poppins Medium, titles DM Serif Display |
| Captions | 6 words, top, type animation |
| Titles | glow, typewriter, slide |
| Transitions | fade (also fade, dissolve, blur) |
| Colour | cinematic, film grain |
| Frame | letterbox |
| On emphasised words | none |
| Sounds | transition: swoosh, motion: click |
| Own colours (no Brand Kit) | #1C1917 and #F5D0A9 |
| Catalog pieces that suit it | caption-editorial-emphasis, caption-weight-shift, grain-overlay, curtain-reveal, focus-blur-resolve, morph-text |

```json
"theme": "editorial"
```

The file: [themes/editorial.json](../../skills/davnai-video/themes/editorial.json). Copy it to `~/.davnai/themes/` to make your own. `"theme_extras": false` turns off the frame, grain and emphasis effects.
